# E-Learning System

A simple e-learning platform for online courses and education.

## Features

- Browse and view courses
- Student and admin dashboards
- Course playlists and content
- User authentication
- Contact and about pages

## Installation

1. Clone the repository:
```bash
git clone https://github.com/omar1175/E-Learning-system.git
```

2. Open `index.html` in your browser

## Technologies

- HTML5
- CSS3
- JavaScript
